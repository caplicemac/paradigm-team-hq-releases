# Paradigm Team HQ

A Windows desktop workspace. Start with a blank board and make it your own.

## Download

Open [the latest release](https://github.com/caplicemac/paradigm-team-hq-releases/releases/latest) and download the Windows Setup executable. Run it once to install.

## Updating

In the app, choose **Check for updates**, then **Download update**, then **Restart and install**. Your local boards and cards are stored separately from the application and remain in place during updates.

This repository distributes the Windows installers and update metadata. It does not contain team workspace data or the source project. The app currently uses local storage; shared team accounts and online synchronization are not included yet.

The current installers are unsigned.
