# Pulsewave

A Windows desktop workspace. Start with a blank board and make it your own.

## Download

Open [the latest release](https://github.com/caplicemac/paradigm-team-hq-releases/releases/latest) and download **Pulsewave-Setup-VERSION.exe**. Run it once to install.

## Updating

In Pulsewave, choose **Check for updates**, then **Download update**, then **Restart and install**. Your local boards and cards stay in place during updates.

The repository address stays unchanged to preserve the original update channel. This repository distributes installers and update metadata; team workspace data and the source project are not published here. The app currently uses local storage; shared accounts and online synchronization are not included yet.

The Windows installers are currently unsigned.
